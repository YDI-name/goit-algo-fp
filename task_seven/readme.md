# Висновки щодо моделювання кидання кубиків методом Монте-Карло

## Опис завдання
За допомогою алгоритму мовою Python було проведено симуляцію кидання двох ігрових кубиків методом Монте-Карло. Кількість ітерацій (кидків) становила 1 000 000. Метою було емпірично визначити ймовірності випадіння кожної можливої суми (від 2 до 12) та порівняти їх із точними аналітичними розрахунками.

## Висновки

1. **Точність методу Монте-Карло:** Отримані за допомогою симуляції результати майже ідеально збігаються з теоретичними (аналітичними) розрахунками. Відхилення становить лише соті частки відсотка (≤ 0.02%).
2. **Закон великих чисел:** Висока точність результатів пояснюється застосуванням Закону великих чисел — чим більша кількість ітерацій (у нашому випадку 1 000 000), тим ближче емпірична частота події наближається до її теоретичної ймовірності.
3. **Нормальний розподіл сум:** Як симуляція, так і аналітичні дані наочно демонструють, що сума «7» є найбільш імовірною (через найбільшу кількість комбінацій: 1+6, 2+5, 3+4, 4+3, 5+2, 6+1), а суми «2» та «12» — найменш імовірними.
4. **Практичне застосування:** Проведена симуляція підтверджує правильність математичної моделі гри в кості та демонструє, що метод Монте-Карло є надійним та ефективним інструментом для розв'язання ймовірнісних задач програмним шляхом, навіть без використання складних комбінаторних формул.
